# MCPM 文档中心

欢迎使用MCPM文档中心！本文档提供了MCPM命令行工具的完整参考资料，包括安装指南、命令参考、使用教程和高级功能说明。

## 关于MCPM

MCPM（MCP Manager）是一个功能强大的命令行工具，用于管理MCP（Model Control Protocol）服务器的完整生命周期。它提供了从初始化、脚手架、开发、部署到监控和维护的全套功能，支持多种云服务提供商和部署环境。
